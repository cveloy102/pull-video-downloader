# PULL Browser Link

Расширение для Microsoft Edge и Google Chrome. Оно нужно для сайтов, которые лучше работают в обычном браузере, в том числе когда вход уже выполнен. Расширение видит сетевые запросы только в тех вкладках, где вы сами включили поиск.

## Установка

1. Откройте `edge://extensions` или `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите эту папку `extension` с файлом `manifest.json`.
4. Закрепите расширение PULL на панели браузера.
5. Запустите PULL для Windows. В настройках скопируйте ключ подключения расширения.
6. Откройте расширение, вставьте ключ в «Подключение к приложению», нажмите «Связать».

## Скачать видео

1. Откройте страницу с видео в Edge или Chrome.
2. Нажмите значок PULL → «Начать поиск». При первом запуске разрешите доступ к сайтам: он нужен для запросов к видеосерверам и встроенным плеерам с других доменов.
3. Нажмите Play на сайте. Если видео уже играло, обновите страницу и запустите его снова.
4. В расширении выберите подходящий HLS, DASH или прямой видеопоток и нажмите «Передать».
5. В PULL откройте раздел «Браузер», выберите полученный поток и начните скачивание.

HLS и DASH обычно предпочтительнее отдельных медиафайлов: они описывают всё видео и доступные дорожки. Загрузка может требовать действующую сессию сайта; устаревший поток найдите снова.

«Остановить» прекращает наблюдение и очищает список этой вкладки. Доступ к сайтам можно отозвать в настройках расширения. Другие вкладки автоматически не включаются. После закрытия браузера активные поиски и найденные потоки забываются.

## Данные и ограничения

Расширение не отправляет ничего на внешние серверы. При явном нажатии «Передать» адрес и нужные заголовки выбранного запроса (включая cookies или Authorization, если сайт их использует) передаются только запущенному локально PULL по `127.0.0.1:17841` с ключом подключения. Все cookies браузера не читаются и не экспортируются. Ключ сохраняется в локальных настройках расширения; захваченные данные живут в памяти сеанса браузера.

Встроенные видеоплееры с HLS/DASH/MSS и запросы fetch/XHR поддерживаются. Расширение не расшифровывает DRM и не извлекает ключи защищённых плееров. Потоки с привязкой к конкретному браузерному соединению, POST-запросам или короткоживущим токенам могут не скачаться. Подписанные адреса передаются без изменения, параметры скрыты только в интерфейсе.

## Протокол локального приложения

- `GET /health` — проверка подключения; заголовок `X-Pull-Token` обязателен.
- `POST /candidate` — JSON `{ "url": "https://…", "title": "…", "mimeType": "…", "headers": { ... } }`; тот же ключ обязателен.
- Сервер слушает только `127.0.0.1:17841`. Успех возвращает JSON с HTTP 200. Неверный ключ — HTTP 401/403.

Документация API: [Chrome webRequest](https://developer.chrome.com/docs/extensions/reference/api/webRequest), [optional permissions](https://developer.chrome.com/docs/extensions/reference/api/permissions).
