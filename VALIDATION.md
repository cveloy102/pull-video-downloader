# Проверка сборки 1.0.0

Проверено на Windows 11 x64:

- 19 автоматических проверок модулей: очередь, конкуренция задач, пауза/продолжение, выбор аудиоформата, ошибки, приватность сессий, распознавание потоков, ограничения IPC-записи, OAuth-окна.
- Сквозной запуск Electron: ввод ссылки в интерфейс, получение форматов, скачивание MP4.
- Скачивание HLS и DASH с локального HTTP-сервера; в готовых файлах FFprobe подтвердил видео и аудио.
- Нажатие Play во встроенном браузере, обнаружение подписанного потока, скачивание с cookie текущей сессии.
- Обнаружение HLS без расширения, отдаваемого как text/plain.
- Локальный мост расширения: запрос без токена отклонён, запрос с токеном принят, выбранный поток передан.
- Загрузка реального внешнего файла https://www.w3schools.com/html/mov_bbb.mp4.
- Запись собственного окна PULL через Windows API с синтезированной тестовой аудиодорожкой. FFprobe подтвердил VP8 и Opus в WebM. Другие окна и системный звук в тест не записывались.
- Собранный EXE: пауза, возобновление с HTTP Range, SHA256 итогового файла совпал с исходным.
- Встроенный WebContentsView виден и имеет корректные размеры; проверен снимок окна Windows.
- Portable EXE самостоятельно распаковывается и запускается, инструменты доступны, расширение копируется в постоянную папку.

Тесты подтверждают эти сценарии, а не поддержку каждого существующего сайта. Полный цикл установленного расширения в пользовательском Edge/Chrome и звук loopback на конкретном аудиоустройстве отдельно не проверялись.

Компоненты: Electron 44.5.1, yt-dlp 2026.08.19, FFmpeg N-127083-g65a3870462-20261001, Node.js 24.19.0. Бинарные инструменты получены из официальных источников; скачанные yt-dlp и FFmpeg проверены SHA256.
