# История версий

## 1.2.1-beta.3

- Светлый установщик PULL с боковой панелью и собственными кнопками окна.
- После нажатия «Обновить» PULL показывает ход установки во время перезапуска и подтверждает обновление после запуска новой версии.

## 1.2.1-beta.2

- Мастер установки и удаления использует оформление PULL, включая фирменную шапку страниц и тёмную строку заголовка окна.

## 1.2.1-beta.1

- «Открыть источник» предлагает подтвердить заново найденный поток перед продолжением загрузки. Потоки с предыдущей страницы исключаются.
- Если файл канала обновлений недоступен, настройки показывают единый статус. Ошибки сети и скачивания отображаются отдельно.
- Запуск и завершение записи блокируют параллельный запуск второй записи.

## 1.2.0

- Обновления из приложения: PULL сам находит новую версию на GitHub, скачивает её в фоне и ставит по кнопке «Обновить».
- Встроенный браузер стал проще: PULL проверяет найденные видео (длительность, качество), отсеивает рекламу, короткие превью и дубли и показывает одну карточку «Видео найдено · Скачать». Остальное спрятано под «Другие варианты».
- Если первая проверка найденного видео не удалась (медленный сайт), PULL повторяет её, прежде чем считать поток нечитаемым.
- Если по ссылке видео не находится, страница сама открывается во встроенном браузере с подсказкой.
- Настройка «Скачивать найденное видео сразу».
- Потоки можно продолжить после перезапуска: данные сессии хранятся зашифрованными (Windows DPAPI). Устаревшую ссылку заменяет кнопка «Открыть источник»: после Play загрузка продолжается с того же места в тот же файл.
- Файлы из браузера называются по заголовку страницы; при совпадении добавляется «(2)», «(3)».
- Строки загрузок больше не мигают при обновлении прогресса, пауза срабатывает с первого клика.
- Уведомления на экране браузера показываются сверху и не прячутся под страницей.
- Портативная версия больше не выпускается: установщик обновляется сам.

## 1.1.0

- Новый интерфейс: узкая панель иконок, строка ссылки, таблица загрузок, светлая тема по умолчанию, тема «Как в системе».
- Свой заголовок окна в стиле приложения, новая иконка, подпись by Cveloy.
- Закрытие окна сворачивает PULL в трей. Меню трея: открыть, скачать ссылку из буфера, приостановить и продолжить все, папка загрузок, выход. Прогресс на панели задач и уведомления о завершении.
- Запуск вместе с Windows в свёрнутом виде.
- Установщик PULL-Setup с ярлыками и удалением данных при деинсталляции.
- Исправления: временные фрагменты и файлы cookie удаляются, ошибки входа распознаются точнее, записи экрана можно перематывать.

## 1.0.0 — первая документированная поставка

- Поиск видео по ссылке, выбор формата и загрузка аудио отдельно.
- Поиск HLS/DASH и других потоков во встроенном браузере.
- Расширение Edge/Chrome для передачи потоков с выбранной вкладки.
- Запись окна или экрана с системным звуком в WebM.
- Очередь, ограничение параллельных загрузок, пауза, продолжение, отмена и история.
- Светлая и тёмная темы.
- Портативная Windows-сборка с необходимыми инструментами внутри.

Более ранние номера выпусков в сохранённом проекте не документированы.
