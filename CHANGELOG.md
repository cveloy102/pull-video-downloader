# История версий

## 1.1.0

- Новый интерфейс: узкая панель иконок, строка ссылки, таблица загрузок, светлая тема по умолчанию, тема «Как в системе».
- Свой заголовок окна в стиле приложения, новая иконка, подпись by Cveloy.
- Закрытие окна сворачивает PULL в трей. Меню трея: открыть, скачать ссылку из буфера, приостановить и продолжить все, папка загрузок, выход. Прогресс на панели задач и уведомления о завершении.
- Запуск вместе с Windows в свёрнутом виде.
- Установщик PULL-Setup с ярлыками и удалением данных при деинсталляции.
- Исправления: временные фрагменты и файлы cookie удаляются, ошибки входа распознаются точнее, записи экрана можно перематывать.

## 1.0.0 — первая документированная поставка

- Поиск видео по ссылке, выбор формата и загрузка аудио отдельно.
- Поиск HLS/DASH и других потоков во встроенном браузере.
- Расширение Edge/Chrome для передачи потоков с выбранной вкладки.
- Запись окна или экрана с системным звуком в WebM.
- Очередь, ограничение параллельных загрузок, пауза, продолжение, отмена и история.
- Светлая и тёмная темы.
- Портативная Windows-сборка с необходимыми инструментами внутри.

Более ранние номера выпусков в сохранённом проекте не документированы.
