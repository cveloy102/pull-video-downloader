# История версий

## 1.0.0 — первая документированная поставка

- Поиск видео по ссылке, выбор формата и загрузка аудио отдельно.
- Поиск HLS/DASH и других потоков во встроенном браузере.
- Расширение Edge/Chrome для передачи потоков с выбранной вкладки.
- Запись окна или экрана с системным звуком в WebM.
- Очередь, ограничение параллельных загрузок, пауза, продолжение, отмена и история.
- Светлая и тёмная темы.
- Портативная Windows-сборка с необходимыми инструментами внутри.

Более ранние номера выпусков в сохранённом проекте не документированы.
